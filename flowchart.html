Flowchart Latihan Algoritma (Nomor 1 - 7)

1. Konversi Celcius ke Reamur dan Fahrenheit

Input: suhu Celcius | Proses: R = 4/5*C, F = 9/5*C + 32 | Output: R dan F

2. Sisi Miring Segitiga Siku-siku

Input: a dan b | Proses: c = sqrt(a^2 + b^2) | Output: sisi miring (c)

3. Menghitung Usia

Input: tahun lahir (tl), tahun sekarang (ts) | Proses: Umur = ts - tl

4. Menguji Suhu: Beku / Cair / Gas

Input: suhu Celcius | < 0 = beku, 0-100 = cair, > 100 = gas

5. Bilangan Terbesar dari n Bilangan

Input: n bilangan | bil pertama jadi maksimum, lalu bandingkan dengan bilangan berikutnya

6. Menentukan Genap / Ganjil / Nol

Input: suatu bilangan | Output: genap / ganjil / nol

7. Akar-akar Persamaan Kuadrat

D = B^2 - 4*A*C | D < 0 = akar imajiner, D = 0 = akar kembar, D > 0 = dua akar
